# Blender Proxy Generator

A Blender addon to automate proxy-generation of high-poly objects to make animation playback smoother.

## Setup

- Download .zip file from [releases](releases)
- In Blender, go to Preferences > Add-ons
- Click on the top-right dropdown > Install from Disk...
- Select the downloaded .zip file

A new "Proxy Generator" panel should appear in the 3D view sidebar (shortcut: N)
